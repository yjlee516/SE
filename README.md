# 소프트웨어공학 실습

## 1주차 실습
- AI를 활용한 랜딩 페이지 제작
- 실습용 프롬프트 제공

## 2주차 실습

인증·홈·상세·작성 화면이 연결되는 블로그를 제작합니다.

### 자료 준비

- 제공받은 시안 이미지 네 장을 프로젝트의 `design/` 폴더에 넣습니다.
- [DB 명세](2주차/db-schema.md)를 프로젝트의 `docs/db-schema.md`에 넣습니다.
- 수업에서 별도로 전달한 접속 정보는 프로젝트 최상위 `.env.local`에 넣습니다.

```text
se-blog/
├─ design/
│  ├─ auth.png
│  ├─ home.png
│  ├─ detail.png
│  └─ write.png
├─ docs/
│  └─ db-schema.md
└─ .env.local
```

### 구현 요청

같은 프로젝트에서 아래 순서로 진행합니다. 각 파일의 내용을 복사하고 해당 시안 이미지를 파일 참조로 선택합니다.

1. [인증](2주차/1-auth): `auth.png`를 참조합니다. DB 명세는 첨부하지 않습니다.
2. [홈](2주차/2-home): `home.png`와 `docs/db-schema.md`를 참조합니다.
3. [상세](2주차/3-detail): `detail.png`를 참조하고 기존 DB 연결 코드·자료형을 활용합니다.
4. [작성](2주차/4-write): `write.png`를 참조하고 기존 코드를 활용합니다. 필요한 구조를 코드에서 확인할 수 없을 때만 명세를 참고합니다.

홈 이후에는 DB 명세를 매번 별도로 첨부할 필요가 없습니다. 공용 DB의 테이블·RLS·시드는 변경하지 않습니다.
